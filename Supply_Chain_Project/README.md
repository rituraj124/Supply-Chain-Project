# Supply Chain Performance & Delivery Analytics

Portfolio project for a Business Analyst / Supply Chain Analytics application.

## Tools
- MySQL
- Python (Pandas, NumPy, Matplotlib)
- Power BI
- DAX

## Business problem
A retail/e-commerce operation wants to understand order volume, delivery performance, warehouse bottlenecks, and inventory risk.

## Dataset
Synthetic data generated for portfolio use:
- 20,000 orders
- 60 products
- 8 warehouses
- 20 suppliers
- 12 monthly inventory snapshots
- 2025 calendar year

## Project workflow
1. Load CSV data into MySQL.
2. Run SQL queries in sql/analysis_queries.sql.
3. Run python/eda.py for EDA and output tables/charts.
4. Import the CSVs into Power BI.
5. Follow powerbi/dashboard_design.md to build the dashboard.
6. Use the interview questions to practice explaining the business problem, analysis, findings, and limitations.

## Suggested portfolio story
"Built a supply-chain analytics solution to monitor order volume, delivery performance, warehouse-level delays, and inventory risk. Used SQL for KPI extraction, Python for EDA, and Power BI/DAX for an interactive operations dashboard."

## Data limitation
This is synthetic data. Results are for demonstration only and do not represent Amazon's actual operations, internal KPIs, or proprietary data.
